# Промпты для последовательного обновления «Логов AdFox»

Передавайте нейросети по одному файлу и строго в указанном порядке:

1. `01_state_and_filters.md` — сохранение состояния и удаление любого фильтра.
2. `02_raw_log.md` — настройка хранения сырого архива.
3. `03_download_progress.md` — фоновая загрузка, скорость, прогресс и блокировка элементов.
4. `04_pause_and_cancel.md` — пауза, продолжение и подтверждаемая отмена.
5. `05_final_audit.md` — общая проверка, документация и подготовка результата.

Каждый этап должен завершаться отдельным коммитом и отправкой одной и той же ветки
`codex/download-improvements` в `origin`. Благодаря этому промежуточные версии будут
видны в GitHub. Следующий этап начинается только после успешного завершения предыдущего.

Если на каком-либо этапе отправка в GitHub не удалась, исполнитель не должен писать,
что этап полностью завершён. Сначала нужно устранить проблему либо сообщить точную
ошибку и оставить готовый локальный коммит.
