# Логи AdFox

Локальное приложение на Python. Скачивает почасовые логи, фильтрует их и сохраняет TSV. Интерфейс работает в браузере, обработка — на вашем компьютере.

## Запуск на macOS

Нужен Python 3.11 или новее. Откройте `start.command`. При первом запуске нужен интернет для установки библиотек. Если двойной щелчок не работает, в Терминале напишите `bash `, перетащите туда start.command и нажмите Enter. Окно терминала оставьте открытым. Остановка: Ctrl+C.

Вручную из папки приложения:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m streamlit run app.py --server.address 127.0.0.1
```

## Запуск на Windows

Нужен Python 3.11 или новее. Дважды щёлкните `start_windows.bat`. При первом запуске потребуется интернет: файл создаст виртуальное окружение и установит библиотеки. Оставьте открытым окно запуска. Чтобы остановить приложение, нажмите Ctrl+C в этом окне.

## Подключение и работа

Приложение использует существующие AWS-профили через boto3. В настройках можно указать профиль; пустое значение использует стандартный поиск доступа boto3. Ключи не записывайте в код или JSON настроек. Endpoint, bucket и папка перенесены из исходного скрипта. Proxy по умолчанию выключен. Может потребоваться рабочая сеть или VPN. Подключение к приватному S3 при разработке не проверялось.

1. Выберите скачивание или локальный `.tsv.gz` / `.tsv`.
2. Укажите дату и час: они используются в имени объекта без преобразования часового пояса.
3. Настройте поля и условия. Каждое значение вводите с новой строки, запятые остаются частью значения.
4. Для скачивания выберите, нужно ли оставить сырой архив после успешной фильтрации.
5. Укажите папку и имя результата, нажмите кнопку запуска.
6. Полный результат сохраняется на диск; интерфейс показывает первые 50 строк и счётчики.

Все фильтры соединяются через И. Внутри списка достаточно одного совпадения. Для отрицательных условий исключается каждое перечисленное значение. Регистр и пробелы учитываются. ID сравниваются как текст: `01` отличается от `1`. Для пустых значений есть отдельные условия.

По умолчанию: `banner_id = 208684` и `flag_virtual = 0`. Это логика исходного скрипта: переменная campaign_ids на самом деле фильтровала banner_id, колонку 11. Для кампаний выберите campaign_id.

Все 101 поле доступны в списке. Неизвестные расшифровки помечены явно; подписи меняются в fields.py. log_headers.tsv содержит по одному имени на строку.

Колонки находятся по заголовку самого лога. Первая строка должна содержать уникальные названия полей. Кодировка UTF-8, разделитель — табуляция. Кавычки не имеют специального значения. Строки с количеством колонок, отличающимся от заголовка, пропускаются и учитываются в счётчике.

Флажок «Оставить сырой лог» относится только к архивам, скачанным приложением из S3. По умолчанию он включён. Если его выключить, новый `.tsv.gz` удаляется только после полностью успешной фильтрации и сохранения итогового TSV. При ошибке полностью скачанный архив остаётся для диагностики или повторной обработки, а временный `.part` удаляется. Архив, который существовал до начала операции, приложение не удаляет. В режиме локального файла исходный `.tsv.gz` или `.tsv` никогда не изменяется и не удаляется независимо от значения настройки.

Для замены существующего файла нужен отдельный флажок разрешения перезаписи. Итоговый TSV заменяется только после успешной обработки. Не запускайте параллельные задания с одинаковыми путями в разных вкладках.

Рабочее состояние сохраняется автоматически после изменений и восстанавливается после полного перезапуска Streamlit. Сохраняются папка результатов, параметры подключения без секретных ключей, AWS-профиль, proxy, источник, настройка хранения сырого лога, путь локального файла, имя результата, дата, час и фильтры. Разрешение перезаписи из соображений безопасности не сохраняется и после нового запуска всегда выключено.

Файл состояния находится вне папки приложения:

- macOS: `~/Library/Application Support/AdFox Logs/state.json`;
- Windows: `%LOCALAPPDATA%\AdFox Logs\state.json`;
- Linux: `$XDG_CONFIG_HOME/adfox-logs/state.json` или `~/.config/adfox-logs/state.json`.

Запись выполняется через временный файл и атомарную замену. Повреждённый или созданный более новой версией приложения файл не мешает запуску: приложение показывает предупреждение и восстанавливает безопасные значения либо корректную часть данных.

«Сохранить настройки» по-прежнему выгружает отдельный JSON для ручного переноса. Для восстановления загрузите его в боковой панели и нажмите «Применить настройки». Старый JSON без даты, режима источника, `keep_raw` и внутренних идентификаторов фильтров поддерживается; для отсутствующего `keep_raw` безопасное значение по умолчанию — оставить архив. Любой фильтр можно удалить кнопкой в его строке; порядок и значения остальных строк сохраняются. Всегда остаётся не менее одного и не более 30 фильтров.

## Как поддерживать

- app.py — интерфейс и запуск операций.
- app_state.py — проверка, восстановление и атомарное сохранение рабочего состояния; управление списком фильтров.
- download.py — S3 через boto3, AWS CLI не требуется.
- operations.py — порядок скачивания, фильтрации и безопасного удаления нового архива.
- filtering.py — построчная обработка, независимая от интерфейса.
- fields.py — подписи полей.
- tests/ — проверки логики и сохранности файлов при ошибках.

Начните изучение с filtering.py: Rule описывает условие, filter_log обрабатывает строки. Большие файлы не загружаются целиком в память. Скорость на реальных объёмах не измерялась, Python может быть медленнее awk.

Проверки из папки приложения:

```sh
python -m unittest discover -s tests -v
```

Для обновления библиотек активируйте окружение и выполните:

```sh
python -m pip install --upgrade -r requirements.txt
python -m unittest discover -s tests -v
```

Перед обновлением сохраните рабочую копию приложения и JSON настроек. requirements.txt задаёт диапазоны версий. requirements-tested.txt фиксирует проверенное окружение Python 3.14 / macOS; его можно передать pip вместо requirements.txt для повторения версий.

Тесты включают независимую проверку состояния и фильтров, а также сценарии интерфейса через Streamlit AppTest.
